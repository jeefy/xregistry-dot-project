# Security Policy

## Reporting Security Issues

The xRegistry maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/xregistry/spec/security/advisories/new) form.

For more details, see the [xRegistry security policy](https://github.com/xregistry/spec/blob/main/SECURITY.md).
